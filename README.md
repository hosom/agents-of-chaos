# Agents of Chaos

This repository is a collection of hooks and SDK agents that extend Copilot.

## Setup

Use Python 3.11+ and sign in to Copilot CLI. Run these commands from the
repository root.

Create a Python virtual environment and install the Parquet dependency:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r hooks/logging/requirements.txt
```

The SDK agents use a separate environment:

```sh
python3 -m venv agents/one_shot/.venv
agents/one_shot/.venv/bin/python -m pip install \
  -r agents/one_shot/requirements.txt
export COPILOT_CLI_PATH="$(command -v copilot)"
```

## Demos

### Session analytics

Start a new Copilot CLI session in this repository and trust it to load
[the logging hooks](.github/hooks/logging.json). They capture session, prompt,
tool, and agent events. SDK agents use the same hooks.

Logs are collected as JSONL and converted to Parquet when the session ends:

```text
logs/sessions/session-<id>/session-<id>.parquet
```

Logs are local and Git-ignored. Full hook payloads can contain sensitive data.
Recover journals left by interrupted sessions with:

```sh
.venv/bin/python hooks/logging/log_tool_call.py recover
```

### Math agent

A [YAML-defined prompt](agents/one_shot/prompts/math.yaml) solves and verifies
a constrained optimization problem using numerical tools.

```sh
agents/one_shot/.venv/bin/python -m agents.one_shot.agent \
  agents/one_shot/prompts/math.yaml \
  --response-model agents.one_shot.models:MathSolution
```

Override the problem with `--param 'problem=Your problem here'`.

### Minesweeper agent

Watch the model solve a board through tool calls, with live board updates and
a final result. Python enforces the game rules; the model makes the decisions.

```sh
agents/one_shot/.venv/bin/python -m agents.one_shot.minesweeper
```

The default is a 6x6 board with six mines and a fresh random seed. The result
includes the seed; pass `--seed 42` to replay a layout. Customize the board with
`--rows`, `--columns`, and `--mines`. By default the agent stops when it cannot
deduce a safe move; `--allow-guesses` permits risky moves.

### Agent output

Both agents stream chat-style progress to stderr and show pretty results on
a terminal. Use `--quiet` to hide progress or `--output json` for structured
results. Redirecting stdout also selects JSON.

Results include `response` and `diagnostics`, with the session ID and failed
tool calls collected by host hooks rather than generated by the model.

## Development

```sh
agents/one_shot/.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m unittest discover -s hooks/logging -p 'test_*.py'
agents/one_shot/.venv/bin/python -m unittest discover \
  -s agents/one_shot -p 'test_*.py'
agents/one_shot/.venv/bin/ruff check .
agents/one_shot/.venv/bin/ruff format --check .
```
